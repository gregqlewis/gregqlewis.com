Cloud Attack Detection Lab

Four AWS attack techniques simulated end to end: IAM enumeration, role-abuse privilege escalation, credential theft, and S3 exfiltration. Each one is captured across CloudTrail, VPC Flow Logs and GuardDuty, with a Sigma rule, a custom Wazuh rule confirmed firing, and an IR playbook.

AI Security Lab: LLM Red Team Assessment

Garak against Meta Llama 3.1 on AWS Bedrock, with findings mapped to MITRE ATLAS and the OWASP LLM Top 10. DAN jailbreaks succeeded 100% of the time and prompt injection up to 71%, while encoding tricks mostly failed. The model's weakness is instruction-following, not content recognition.
