AI Security Lab

Repository on GitHub

Garak run against Meta Llama 3.1 on AWS Bedrock. DAN jailbreaks succeeded every time and prompt injection up to 71% of the time, while encoding tricks mostly failed. The weakness is in how the model follows instructions, not in what it recognizes.

Mapped to
MITRE ATLAS, OWASP LLM Top 10
Built with
Garak, AWS Bedrock
